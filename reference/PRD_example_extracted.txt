2. Architectural Design & Engineering Stack
The codebase is constructed around modular separation of concerns. UI state is driven by React 19 concurrent features, styles are managed via Tailwind CSS v4's CSS-first theme tokens, and data is abstracted away into editable schema definitions.
2.1 Frontend Tech Stack Breakdown
Core Library: React 19 (react & react-dom ^19.2.7): Modern component tree utilizing state hooks, portals, and concurrency.
Build Tool: Vite (^8.1.1): Ultra-fast ES module build tool providing lightning-fast HMR and minimal production bundling overhead.
Styling Framework: Tailwind CSS v4 (^4.3.3): CSS-first configuration using @theme directives in index.css without requiring external legacy JS config files.
Motion System: Framer Motion (^12.42.2): Production animation orchestrator managing page entrance reveals, modal scale transitions, and spring physics.
Graphics: HTML5 2D Canvas: Native browser canvas rendering autonomous particle collisions and dynamic proximity networks.
Tooling: Oxlint (^1.71.0): Rust-powered high-speed linter enforcing clean code quality and catching React anti-patterns.

3. Functional Modules & Implementation Details
3.1 Interactive Physics & Custom Hooks
Dynamic Section Tracking: useActiveSection(ids): Observes section elements via IntersectionObserver with weighted intersection ratios to immediately reflect the user's active viewport position in the navbar.
Scroll Metric Engine: useScrollProgress(): Computes document scroll metrics (scrollTop / (scrollHeight - clientHeight)) with passive event listeners to drive both the progress bar and back-to-top button.
Performance Cursor Tracker: usePointer(): Directly captures pointer coordinates in a React useRef to prevent triggering 60+ re-renders per second, maintaining maximum UI frame rates.
Particle Network: InteractiveCanvas.jsx: Employs 65 floating particles calculating Euclidean proximity distance: d = sqrt((x1 - x2)^2 + (y1 - y2)^2). When d < 120px, an alpha-blended connection vector is drawn dynamically.
Magnetic Micro-Interaction: MagneticButton.jsx: Calculates pointer coordinates relative to the button bounding box, exerting a magnetic spring pull on hover with configurable stiffness and damping.
3.2 About Section 3D & Vector Widgets
CSS 3D Engine: Pure CSS 3D Rubik's Cube: Features 6 faces rotated in 3D perspective (transform-style: preserve-3d) with custom continuous keyframe rotations without third-party 3D WebGL bloat.
Full-Stack Terminal: Terminal REST Simulator: Animated developer console simulating live GET /api/ requests with automated typing steps and pulsing database connection indicators.
Robot Optics: Cybernetic Sensor Animation: Custom robot scanning eye with sweeping laser beam and radial gradient pupil.

4. Built-in Chess Engine & AI (index.html)
To create an unforgettable impression reflecting Sumit's 2-Time Inter-College Chess Championship background, an interactive zero-dependency chess engine is embedded directly in the platform:
Data Structure: 0x88 Board Array Representation: Standard 128-element single-dimensional array where (sq & 0x88 !== 0) instantly filters out illegal off-board calculations in O(1) time.
Move Validation: Full Legal Move Generation: Evaluates pseudo-moves, applies moves to a cloned board state, verifies king attack security (isAttacked), and enforces castling, en-passant, and pawn promotion.
Automated Engine: Heuristic AI Evaluator: Evaluates material advantages using classical point metrics (P:1, N:3, B:3, R:5, Q:9, K:0) to generate tactical counter-moves against human players.

6. Non-Functional Requirements & Security
Layout Stability: Zero Cumulative Layout Shift (CLS): Explicit dimensioning on all graphical assets and canvas viewports.
Accessibility: Reduced Motion Auditing: Respects @media (prefers-reduced-motion: reduce) by truncating animation cycles to 0.001ms for vestibular-sensitive users.
SEO Optimization: Structured Search Data: Integrates schema.org Person entity in JSON-LD format with complete sameAs links and skill taxonomy.
Security: External Boundary Hardening: All outbound hyperlinks implement rel='noopener noreferrer' to prevent reverse tabnabbing.
7. Developer Reference & Handover Guide
To help your friend configure or adapt this repository as a reference architecture, follow this concise step-by-step handover checklist:
Handover: Step 1 (Dependencies): Run 'npm install' to fetch React 19, Tailwind v4, and Vite.
Handover: Step 2 (Local Testing): Run 'npm run dev' and open http://localhost:5173 to test HMR.
Handover: Step 3 (Resume Replacement): Replace public/resume.pdf with the candidate's actual PDF document.
Handover: Step 4 (Data Personalization): Edit skills in src/data/skills.js, projects in src/data/projects.js, and work experience in src/data/experience.js.
Handover: Step 5 (Contact Form Wiring): Connect handleSubmit in src/sections/Contact.jsx to an API service (Formspree, EmailJS, or Resend).
Handover: Step 6 (Production Build): Execute 'npm run build' to output optimized static bundles to dist/.
